# 未解決の問題と、実機でまだ確かめていないこと（第135版）

ここに書いたものは「直した」とは言えないものです。試験はすべて偽物のサーバー（ゲームの仕組みをまねた試し場）で行っており、実機の Minecraft では一度も通しプレイしていません。

## 実機でしか確かめられないこと
- 暗転のあとに本当に移動するか（teleport・tickingarea の実際の動き、低性能の端末でのチャンク読み込みの時間）。試し場では全148話・暗転すべてで目的地に着いた。
- 崩壊・炎上・洪水・地割れ・石化・消滅の見え方（粒子・音・揺れ・カメラ）。炎上中の燃え広がり止め・天気・霧の切りかえ。
- 敵の登場の「集中線の代わり」（敵のまわりの放射の粒）が強調に見えるか。
- 相棒の専用の見た目と動き。リソースパックの版を上げていないため、古いパックが端末に残らないか。
- 王都（約90人＋城内約22人）の重さ。店の中の人の見え方。夜に見ている前で住民が消えることがある。
- ボスの仕掛けの強さと見え方。
